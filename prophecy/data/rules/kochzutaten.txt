# Kuechenregeln als DATEN -- 24.11.2026.
#
# Form: `<wort>: a, b, c`.  Eine Zeile je Sammelwort, `#` ist Kommentar.
#
# Zwei Dinge stehen hier:
#
# 1. `fluessig` -- was in einen Topf gehoert.  Die ART `liquid` traegt Teer,
#    Lack, Saeure und Kuehlmittel; in einem Brotrezept ist das kein Fehler
#    des Zufalls, sondern der Warengruppe.  Diese Namen sind alle `food`.
#
# 2. Die Sammelwoerter aus Gerichtsnamen.  `grain_cake` nennt kein Korn,
#    meint aber eins; `fish_chowder` nennt keinen Fisch, meint aber einen.
#    Steckt dagegen ein echter Stoffname im Gerichtsnamen (`rye_loaf`,
#    `honey_bun`, `oat_porridge`), hat der Vorrang -- diese Liste greift nur,
#    wenn das Gericht in Sammelbegriffen spricht.
#
# Heisst ein Schluessel wie eine ART (`liquid`, `animal`, `herb`), dann
# ersetzt seine Liste in Kuechenrezepten den Topf dieser Art.  So steht die
# Ausnahme als Daten da und nicht als Artvergleich im Code (spec/49 Section 16).
# `essbar` sagt, aus welchen Arten eine Leitzutat kommen darf.
#
# Reihenfolge zaehlt: das erste passende Wort gewinnt, darum stehen die
# engeren Begriffe vor den weiteren.
essbar: food, fungus, herb
# Was vom Tier in einen Topf gehoert.  Die ART `animal` traegt Hufe,
# Kaeferfluegel und Schuppen -- `bone_broth` aus `beetle_wing` war die Folge.
