# Disease-Tag-Pools

Pro disease.kind eine Tag-Liste die das disease_head der Foundation-
Architecture-Architektur als Output-Vokabular benutzt.  Auch Quelle für
`Remedy.cures_tags` Matching und Resistance-Berechnung
(`creature.attrs.resistance_tags`).

| Kind | Datei |
|---|---|
| 1 | `toxic_tags.txt` |
| 2 | `biological_tags.txt` |
| 3 | `physical_tags.txt` |
| 4 | `magical_tags.txt` |
| 5 | `mental_tags.txt` |
| 6 | `environmental_tags.txt` |
| 7 | `genetic_tags.txt` |

Plus `universal_disease_tags.txt` für domain-übergreifende Modifier
(severity-Levels, propagation patterns).
